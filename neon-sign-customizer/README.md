# Neon Sign Customizer

Šis spraudnis pievieno **[neon_sign_customizer]** īskodu, kas parāda neona zīmes pielāgošanas interfeisu ar reāllaika priekšskatījumu.

## Uzstādīšana

1. Nokopējiet mapi `neon-sign-customizer` uz `wp-content/plugins/` direktoriju.
2. WordPress administrācijas panelī atveriet **Spraudņi → Installed Plugins** un aktivizējiet **Neon Sign Customizer**.

## Lietošana

Ievietojiet īskodu jebkurā lapā vai ierakstā:

```
[neon_sign_customizer]
```

Pēc saglabāšanas lapā parādīsies pielāgošanas panelis un dzīvais priekšskatījums.

## Piezīmes

- Spraudnis automātiski ielādē nepieciešamos fontus no Google Fonts.
- Ja izmantojat kešatmiņu (cache) spraudņus, pēc aktivizēšanas notīriet kešatmiņu.
